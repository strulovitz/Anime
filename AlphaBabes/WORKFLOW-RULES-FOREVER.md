# 🔐 WORKFLOW RULES — FOREVER

## REFERENCE IMAGE RULE

Before giving Nir ANY entity prompt link, check the .txt file for species/entities that have already been generated as images. If the prompt mentions a species, character, creature, or object that has a reference image in `AlphaBabes/images/`, you MUST:

1. Add "REFERENCE IMAGES ATTACHED" instructions at the TOP of the .txt file (before the Global Style Prefix), listing each reference image name and a brief description of what it looks like.
2. Provide Nir with BOTH the prompt link AND the reference image links.
3. Commit the updated .txt to the repo immediately.
4. NEVER skip this check — every prompt, every time, forever.
