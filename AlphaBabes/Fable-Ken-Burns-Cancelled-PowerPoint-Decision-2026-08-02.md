And here is the good news: you don't need to buy ANY new tool. You already own two tools that handle 1:1 perfectly:
✅ Option 1 — PowerPoint (my recommendation for you)

PowerPoint does everything you described, and you already know it:

    Slide size can be ANY proportion, including square: Design → Slide Size → Custom Slide Size → set e.g. 26.67 cm × 26.67 cm (square). The image fills the slide perfectly, 100% visible, zero cropping.
    Insert Madie's narration on each slide: Insert → Audio → Audio on My PC → choose the MP3 from ElevenLabs → set it to "Play Automatically."
    Auto-advance: Transitions → uncheck "On Mouse Click," check "After: [duration of that slide's narration]."
    Export as a real video file: File → Export → Create a Video → it produces an MP4 you can play anywhere, send to Madie's phone, upload to YouTube.
    You can even add the opening/ending songs and gentle transitions (a simple "Fade" between slides looks elegant and cinematic — that's all you need).

This is the safest path for a complete beginner with a deadline tomorrow. One familiar tool, start to finish.
✅ Option 2 — Premiere with a square sequence (if you prefer)

Premiere does not force 16:9! When creating the sequence: File → New → Sequence → Settings tab → set Frame Size to 1080 × 1080 (square). Your images fill the frame exactly, whole picture visible, no bars, no zoom, no crop. Just: image + narration audio + music + fades. YouTube accepts square videos fine (it adds neutral bars automatically on wide screens).
✅ Option 3 — 16:9 with "blur-fill" (only if you want widescreen later)

The professional trick used in documentaries for square footage: the whole square image sits centered and untouched, and the empty sides are filled with a blurred, enlarged copy of the same image. Nothing is lost, and it looks intentional and beautiful. This can wait for Pass 2 — mentioning it only so you know it exists.
